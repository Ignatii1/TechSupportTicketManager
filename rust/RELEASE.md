**Прототип TicketBoard на Rust** — чтобы сравнить размер, память и скорость с нынешним TicketBoard.exe. Это не замена:
умеет только доску, перенос карточек (до выхода), трей, глобальную клавишу и чтение одной заявки из Интрасервиса.
**Ничего не пишет** — ни `tickets.json`, ни `settings.json`, ни в Интрасервис.

Как попробовать:

1. Скачать `ticketboard-rs.exe` и положить рядом с `TicketBoard.exe`: он читает `tickets.json` и `settings.json` из своей
   папки. TicketBoard.exe может работать в это время.
2. Запустить. Внизу окна — цифры: размер exe, память, через сколько окно на экране после запуска.
3. Сравнить с TicketBoard.exe в Диспетчере задач (вкладка «Подробности», столбцы «Рабочий набор» и «Память (частный
   рабочий набор)») — с открытым окном и в трее через минуту. Запуск — после перезагрузки, первый раз.
4. Перетащить карточки, прокрутить колонки, поменять размер окна, переключить тему Windows (светлая / тёмная).
5. Выбрать карточку с номером → «Прочитать из Интрасервиса». Ответ или ошибку можно выделить и скопировать — пришлите,
   особенно строку «Сеть»: по ней видно, нужен ли переносу прокси.
6. Закрыть окно — значок в трее; `Ctrl+Alt+Shift+Space` — показать / спрятать (`Ctrl+Alt+Space` у TicketBoard.exe);
   «Выход» — в меню значка.

Windows может предупредить (SmartScreen): exe не подписан, как и TicketBoard.exe.
